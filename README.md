# Pairs Trading：一个失败的统计套利实验

我想做一个配对交易策略。做完了，没赚到钱。

7 个经典候选对——KO/PEP、XOM/CVX、V/MA、GLD/GDX、USO/XLE、EWA/EWC、EWJ/EWG——2010 到 2024 的日线数据。FDR 校正后零幸存，Bootstrap 置信区间覆盖 0，扣掉佣金、滑点、借券费之后，样本外 Sharpe 是负的。

但我没有删掉这个仓库。因为"为什么没赚到钱"比"赚到了"更有意思。协整关系在 15 年尺度上处处失效（CUSUM 7/7 拒绝参数稳定），门控只在 13–20% 的时间开放，唯一正收益的 regime 是 COVID 那 253 天。

这个仓库是我的完整研究记录：代码、数据、图表、一篇讲清楚"哪里错了"的研究笔记，以及一套可以搬到别的均值回归研究上的诊断工具。

## 我做了什么

**数据**：yfinance 调整后收盘价，2010-01-04 到 2024-12-31，日线，14 只标的。

**选队**：只在样本内（2010–2018）做 Engle-Granger 协整检验，按 p 值 + 经济逻辑 + OU 半衰期上限（180 天）筛。全样本 p 值只做诊断对照，不参与选队。

**Beta**：滚动 OLS，试了 30/60/120 天窗口，另外写了一个 Kalman Filter 做对比。禁止全样本 Beta。

**信号**：对数价差 `log(y) - beta_t * log(x)`，滚动 60 天 Z-Score，entry ±2.0 / exit ±0.5 / stop ±3.5，时间止损用 2 倍样本内半衰期。信号收盘确认，次日执行。

**成本**：佣金 5bps + 滑点 5bps，借券费年化 100bps。流动性门槛 20 日均成交额 > $10M。

**验证**：样本内 2010–2018，样本外 2019–2024。Walk-forward 每 6 个月用过去 3 年重新选对、重估 Beta、重调参。参数敏感性只跑样本内。

## 结果

净口径，含全部成本：

| 口径 | 年化 | Sharpe | 90% CI |
|---|---|---|---|
| EWJ/EWG 样本内 | +0.98% | 0.18 | — |
| EWJ/EWG 样本外 | −0.52% | −0.10 | [−0.72, +0.56] |
| Walk-forward（23 折） | −0.45% | −0.06 | — |
| 门控篮子样本外 | +0.8% | +0.29 | [−0.55, +1.13] |

四条独立证据链指向同一个结论：

1. 91 个组合里最小 raw p=0.0065，FDR 校正后 p=0.594，零幸存
2. 滚动协整门控只有 13–20% 的时间开放
3. CUSUM 检验 7/7 对拒绝参数稳定
4. 零成本毛 Sharpe 也只有 0.1–0.2，基准成本即转负

Kalman 对冲比更平滑，但样本外 Sharpe 更差（−0.41 vs −0.10）。动态 Beta 不是免费的午餐。

## 我又追问了一层

负结果本身也需要检验。所以做了深度诊断（研究笔记 §7）：

**Regime 分样本**：篮子 OOS 的 +0.29 几乎全部由 COVID 2020 一年贡献（Sharpe +2.21）。QE 低波动期 −0.41，加息期 −0.86。没有稳定赚钱的常态 regime。

**留一法**：剔除 GLD/GDX 后，篮子 OOS Sharpe 从 0.29 归零（−0.07）。篮子实际上是"一对赚钱 + 六对噪声"。随机权重基线里，实际权重只排第 67 百分位。

**基准对比**：同期 SPY 买入持有 Sharpe 0.86。策略的优势只在低回撤和市场中性（对 SPY 的 β = −0.01，R² = 0.005）。

**随机信号**：同暴露同成本下，策略排第 88 百分位。显著好于抛硬币，但 edge 厚度有限。成本占毛 PnL 的 63%——佣金和滑点各约 25%，借券 14%。

**CUSUM 断点**：能源对的断点在 2015 年（油价崩盘），其余各对的断点落在样本前 18 个月。它们从未进入稳定协整状态。

**功效分析**：检测 Sharpe 0.3 需要 91 年样本。15 年只够分辨 Sharpe ≳ 1。CI 覆盖 0 有一部分是功效不足的必然结果——不是"没 edge"，是"测不出来"。

## 防前视偏差

这部分我做得比较小心：

1. 选队、半衰期、参数网格搜索只用样本内数据
2. Beta 和 Z-Score 都是滚动估计，时点 t 只用 ≤ t 的数据
3. 信号 T 日收盘确认，T+1 日执行
4. Walk-forward 每 6 个月重选队、重估 Beta、重调参
5. 开仓后该笔交易内对冲权重固定，不做每日 beta 再平衡

代码层面有单元测试验证无泄漏（`tests/test_core.py`）。

## 我做得不好的地方

**幸存者偏差**：标的都是当前存续的大盘股和 ETF。我没有 WRDS/CRSP，拿不到退市资产。严格做法需要含退市标的。ETF 和超大蓝筹的退市概率低，但偏差方向仍然存在。

**数据粒度**：yfinance 日线。没有买卖价差报价，没有借券可得性和真实费率的报价。成本用固定 bps 近似，没有建模市场冲击。

**执行假设**：信号 T 日收盘确认、T+1 日按收盘价成交。没用开盘价或分钟数据。真实执行会有偏差。

**统计功效**：15 年日线只够分辨 Sharpe ≳ 1 的策略。Sharpe 0.1–0.3 量级的 edge 在这个样本长度下本来就无法与 0 区分。这是数学事实，不是我的代码问题。

**结论的适用范围**：失效结论适用于"2010–2024、日频、这 7 个候选对、Z-Score 信号"这一组合。不代表配对交易在其他宇宙或频率下无效。

## 我一开始想错了什么

我原以为 KO/PEP 一定协整。可口可乐和百事，同一个行业，差不多的产品。结果样本内 p=0.354——完全不显著。

我原以为多对组合一定能分散风险。结果 7 对之间的平均相关性 ≈ 0，组合 Sharpe 提升只是数学上的分散效应，不是真实 edge。

我原以为 Kalman Filter 会比滚动 OLS 好。结果更差，半衰期 746 天，接近随机游走。

我原以为 91 个组合里总能找到几个显著的。确实找到了——最小 raw p=0.0065。但 FDR 校正后 p=0.594。多重检验陷阱的教科书案例。
